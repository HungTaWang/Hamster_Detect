# 🐹 Hamster Detect (倉鼠手勢比對)

這是一個基於網頁與 AI 視覺技術的互動式手勢辨識專案。透過攝影機捕捉使用者的手部動作，並即時轉換為對應的可愛倉鼠迷因照片！

## ✨ 核心功能
* **即時手部追蹤**：使用 Google MediaPipe Tasks Vision API 進行高幀率、低延遲的 21 關鍵點手部骨架追蹤。
* **抗旋轉的真實 3D 角度偵測**：摒棄傳統容易受手部傾斜影響的「指尖到手腕 2D 距離法」，全面改用「3D 空間關節夾角法」。
* **精準手心/手背判別**：支援前鏡頭鏡像翻轉下的手掌正反面判定。
* **流暢的動態 UI**：以 Glassmorphism (毛玻璃) 風格打造的使用者介面，提供即時的骨架疊加與 Debug 數據面板。

## 🧠 程式運作邏輯與技術細節

### 1. 手指伸直/彎曲判斷（3D 內積法）
為了準確判斷手指是否伸直，程式讀取了 MediaPipe 提供的 `(x, y, z)` 三維座標，並針對每根手指計算其 **PIP（第一指節）** 與 **DIP（第二指節）** 的空間夾角：
* 利用向量內積 (Dot Product) 計算三個關節點構成的夾角餘弦值 ($\cos \theta$)。
* 當 $\cos \theta < -0.5$（即夾角大於 120 度）時，視為該關節處於「伸直」狀態。
* 只有當第一與第二指節都同時滿足伸直條件時，該手指才被判定為 `Up`。
* **優勢**：因為加入了 `z` 軸深度，即使手心正對鏡頭比「讚」或「V」，手指沿著相機深度方向彎曲也能被精準捕捉。

### 2. 手心 / 手背判斷（2D 外積法）
透過取得「手腕(Wrist)」、「食指根部(Index MCP)」、「小指根部(Pinky MCP)」三個關鍵點，計算兩向量的 2D 外積 (Cross Product)：
* 由於前鏡頭畫面會進行鏡像翻轉，MediaPipe 會將畫面上實際的右手識別為 `Left`。
* 程式根據 MediaPipe 回傳的左右手分類 (`handedness`)，配合外積的正負號，完美校正了鏡頭翻轉帶來的正反面誤判。

## 📸 手勢判別標準與對應照片

程式會根據辨識出的手指狀態 (`thumbUp`, `indexUp`, `middleUp`, `ringUp`, `pinkyUp`) 以及雙手數量，進行嚴格的條件匹配。

### 👐 雙手手勢 (Double Hands)
| 手勢名稱 | 判定標準 (Criteria) | 觸發效果 |
| :--- | :--- | :--- |
| **雙手比 YA** | 雙手皆只有「食指」與「中指」伸直 | `✌️✌️ 雙手比YA → 倉鼠雙手YA！` |
| **雙手比讚** | 雙手皆「拇指」伸直，且每隻手伸直的手指 $\le 2$ 根 | `👍👍 雙手比讚 → 倉鼠歡呼！` |
| **雙手張開** | 雙手皆有 $\ge 4$ 根手指伸直 | `🖐️🖐️ 雙手張開 → 倉鼠嚇到！` |
| **雙手握拳** | 雙手伸直的手指數量皆為 $0$ | `✊✊ 雙拳握緊 → 倉鼠生氣！` |
| **手心手背** | 一隻手判定為「手心」，另一隻手判定為「手背」 | `🤲 手心手背 → 倉鼠愛心！` |
| **任意雙手** | 未符合上述條件，但畫面上偵測到兩隻手 | `👐 雙手出現 → 倉鼠歡呼！` |

### ✋ 單手手勢 (Single Hand)
| 手勢名稱 | 判定標準 (Criteria) | 觸發效果 |
| :--- | :--- | :--- |
| **比讚 (Thumbs Up)** | 「拇指」伸直，且其餘四指必須**全部彎曲** | `👍 比讚 → 倉鼠讚！` |
| **勝利 (Victory / YA)** | 「食指」與「中指」伸直，「無名指」與「小指」彎曲 | `✌️ 比YA → 倉鼠舉手！` |
| **指向 (Pointing)** | 只有「食指」伸直，中指、無名指、小指皆彎曲 | `☝️ 指向上 → 倉鼠帥！` |
| **我愛你 (I Love You)**| 「拇指」、「食指」、「小指」伸直，其餘彎曲 | `🤟 我愛你 → 倉鼠愛心！` |
| **搖滾 (Rock)** | 「食指」與「小指」伸直，中指與無名指彎曲 | `🤘 Rock → 倉鼠帥！` |
| **打招呼 (Open Palm)** | 伸直手指 $\ge 4$ 根，且手勢判定為**手心** | `🖐️ 手心打招呼 → 倉鼠嗨！` |
| **手背 (Open Back)** | 伸直手指 $\ge 4$ 根，且手勢判定為**手背** | `🫲 手背 → 倉鼠害羞！` |
| **握拳 (Fist)** | 伸直手指數量為 $0$ | `✊ 握拳 → 倉鼠生氣！` |
| **三指 (Three)** | 剛好有 $3$ 根手指伸直 (未完全符合其他手勢) | `🤔 三指 → 倉鼠困惑！` |
| **未知 (Unknown)** | 偵測到手部，但未符合上述任何單手手勢 | `❓ 看不懂 → 倉鼠困惑...` |

## 🚀 本地端執行方式

1. 確保已安裝 Node.js。
2. 進入專案目錄並安裝依賴：
   ```bash
   npm install
   ```
3. 啟動 Vite 開發伺服器：
   ```bash
   npm run dev
   ```
4. 在瀏覽器開啟 `http://localhost:5173/` 即可體驗！
